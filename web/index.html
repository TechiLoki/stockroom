A SMALL GUIDE TO CLEAN IMPORTS

Know what changes, before anything changes.

  1. Upload CSV or XLSX. The first non-empty row becomes the header. Formulas, errors, unsupported workbooks and oversized data are flagged or rejected.
  2. Map your columns. SKU, product name, quantity and unit price are required. Currency and effective date can use batch defaults.
  3. Review the exact issues. Duplicate SKUs invalidate all occurrences. Correct the source and reupload, or explicitly import valid rows only.
  4. Choose the stock rule. Replace uses the supplier’s stock count. Add treats quantities as a new delivery. Give each genuine delivery a unique supplier reference.
  5. Keep a paper trail. Completed imports retain row outcomes, error reports and before/after inventory changes.
Repeat the same file, supplier reference and settings to retrieve the existing batch without adding stock again. Changed content under an existing reference is a conflict. A new reference is a new business event.

Prices use exact minor-unit arithmetic. Currency changes never imply conversion. Older replacement snapshots are skipped; older additive deliveries preserve the latest product metadata. Dates must be ISO text, not Excel date serial numbers.
