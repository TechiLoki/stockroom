# Stockroom: CSV & Excel Inventory Importer

Role: TypeScript Developer | Node.js, PostgreSQL & Data Validation

Supplier inventory importer with CSV/value-based XLSX support, column mapping, dry-run previews, duplicate detection, exact price/date validation, and safe row-level error reports. TypeScript/Node API and worker apply explicit replace/add stock rules through transactional PostgreSQL APIs. Supplier references prevent accidental reimports, while history retains outcomes and before/after changes. Personal project with synthetic examples and Docker setup.

Skills: TypeScript, Node.js, PostgreSQL, Data Processing, Docker
